## 2. Track A — SoC / Embedded Software Integration (Vitis, PetaLinux, PYNQ, Bare-Metal, XSDB)

### 2.1 Required Handoff Files
- **Hardware Platform / Bitstream:** `canary_fir.xsa` (exported with `write_hw_platform -fixed -include_bit` for Vitis, PetaLinux, and XSDB) and/or `canary_fir.bit` (plus `.hwh` if targeting PYNQ).
- **Register & Bring-Up Helpers:** [sw/canary_fir_regs.h](sw/canary_fir_regs.h) (C99/C++), [sw/canary_fir_regs.py](sw/canary_fir_regs.py) (Python/PYNQ MMIO), and [bringup/jtag_bringup.tcl](bringup/jtag_bringup.tcl).
- **Golden Loopback Vectors:** [test_vectors/canary_stim.mem](test_vectors/canary_stim.mem), [test_vectors/canary_exp_default.mem](test_vectors/canary_exp_default.mem), and [test_vectors/canary_exp_custom.mem](test_vectors/canary_exp_custom.mem).

### 2.2 Programming & PS-PL Release Sequence
1. **Standalone JTAG Bring-Up (`SW6 = 0000` on ZCU102):** Run [bringup/jtag_bringup.tcl](bringup/jtag_bringup.tcl) via XSDB (see [bringup/README_BRINGUP.md](bringup/README_BRINGUP.md)):
   ```powershell
   xsdb bringup/jtag_bringup.tcl C:\path\to\canary_fir.xsa 0xA0000000
   ```
   This executes the mandatory Zynq UltraScale+ MPSoC sequence: `rst -system` -> `psu_init` -> `fpga -no-revision-check` -> `psu_post_config` -> `psu_ps_pl_isolation_removal` -> `psu_ps_pl_reset_config`. **Never** run `fpga -f` alone without PS initialization and isolation removal, or AXI reads will hang (`DAP ACK` timeout).
2. **Linux / PYNQ / Booted SoC:** If U-Boot/Linux/FSBL already initialized PS, load the overlay/bitstream and ensure `clk_wiz_core/locked` is asserted before accessing `0xA0000000`.

### 2.3 Base Address & AXI4-Lite Register Quick-Reference
- **Base Address in [`vivado/create_bd.tcl`](vivado/create_bd.tcl):** `0xA0000000` (`256 B` window, `8-bit` byte offset).
- **`WSTRB` Requirement:** Always execute 32-bit aligned writes (`wstrb = 4'hF`). `CTRL` (`0x04`) and `STATUS` (`0x08`) check `wstrb[0]`, and `COEFF[0..7]` (`0x10..0x2C`) require `wstrb[1:0] == 2'b11`.

| Offset | Name | Access | Reset Value | Description |
| :---: | :--- | :---: | :---: | :--- |
| `0x00` | `VERSION` | `RO` | `0x46495231` | Constant 4-byte ASCII ID `"FIR1"` |
| `0x04` | `CTRL` | `RW` | `0x00000000` | `[0]`: `bypass_en` (`1` = bypass, `0` = normal FIR) |
| `0x08` | `STATUS` | `R/W1C` | `0x00000000` | `[0]`: `ovf_sticky` (latched on saturation; write `1` to clear) |
| `0x10..0x2C` | `COEFF[0..7]` | `RW` | `[-214, -327, 0, 992, 2525, 4351, 5839, 6435]` | Signed 16-bit Q1.15 symmetric taps `h0..h7` in `[15:0]` (sign-extended on read; `COEFF[7]` @ `0x2C` = `0x00001923`) |

### 2.4 Minimal C & Python Integration Examples

#### C / Vitis Bare-Metal ([`sw/canary_fir_regs.h`](sw/canary_fir_regs.h))
```c
#include "canary_fir_regs.h"

uintptr_t base = CANARY_FIR_DEFAULT_BASE_ADDR;
uint32_t ver = canary_fir_mmio_read32(base, CANARY_FIR_REG_VERSION);
if (ver != CANARY_FIR_VERSION_EXPECTED) {
    /* Stop: check PS-PL isolation removal, clk_wiz lock, or base address */
}

/* Optional: load custom Q1.15 symmetric taps, then flush 14 zero samples via DMA */
static const int16_t custom_taps[CANARY_FIR_NUM_SYM_TAPS] = {
    0, 0, -512, 0, 2048, 4096, 6144, 9215
};
for (uint32_t k = 0; k < CANARY_FIR_NUM_SYM_TAPS; k++) {
    canary_fir_mmio_write32(base, CANARY_FIR_REG_COEFF(k),
                            canary_fir_pack_coeff(custom_taps[k]));
}

/* Clear sticky overflow flag (R/W1C) */
canary_fir_mmio_write32(base, CANARY_FIR_REG_STATUS, CANARY_FIR_STATUS_OVF_STICKY_MASK);
```

#### Python / PYNQ ([`sw/canary_fir_regs.py`](sw/canary_fir_regs.py))
```python
from pynq import MMIO
from canary_fir_regs import ADDR_WINDOW_BYTES, CUSTOM_COEFFS, DEFAULT_BASE_ADDR, CanaryFirMmio

fir = CanaryFirMmio(MMIO(DEFAULT_BASE_ADDR, ADDR_WINDOW_BYTES))
fir.check_version()                 # Raises RuntimeError unless 0x46495231 ("FIR1")
fir.write_coeffs(CUSTOM_COEFFS)     # Next step: push 14 zeros through DMA to flush SRLs
fir.clear_overflow_sticky()         # W1C clear of STATUS[0]
```

### 2.5 DMA Loopback & Operational Rules
- **DMA Geometry (`vivado/create_bd.tcl`):** `axi_dma` is configured in simple register mode (`c_include_sg = 0`), 32-bit AXI-MM connected to PS `S_AXI_HP0_FPD`, and 16-bit AXI4-Stream (`M_AXIS_MM2S -> fir_core/s_axis`, `fir_core/m_axis -> S_AXIS_S2MM`).
- **Sample Format & `TLAST`:** Input/output streams carry signed 16-bit Q1.15 (`1.0 == 32768`, 2 bytes/beat). Assert `TLAST` on the final sample of each DMA packet; `canary_fir` preserves `TLAST` 1:1 on the aligned output beat.
- **Reconfiguration Zero-Flush:** Because the 14-sample shift chain `d[0:13]` is reset-free, push **14 zero samples** (`CANARY_FIR_FLUSH_ZEROS = 14`) after rewriting `COEFF[0..7]` (or toggling `CTRL[0]` bypass) before sending the next payload burst.
- **Golden End-to-End Verification:** Stream the 256 signed 16-bit values from [test_vectors/canary_stim.mem](test_vectors/canary_stim.mem) via MM2S -> `canary_fir` -> S2MM and verify sample-for-sample match against [test_vectors/canary_exp_default.mem](test_vectors/canary_exp_default.mem) (or `fir_fixed()` in [python/canary_fir_golden.py](python/canary_fir_golden.py)).

## 3. Track B — FPGA RTL / Subsystem Integration (Top-Level RTL or Vivado IPI BD)

### 3.1 Required Source Files
- **SystemVerilog RTL:** [rtl/axis_skid.sv](rtl/axis_skid.sv), [rtl/canary_fir_regs.sv](rtl/canary_fir_regs.sv), [rtl/canary_fir_core.sv](rtl/canary_fir_core.sv), and [rtl/canary_fir_top.sv](rtl/canary_fir_top.sv).
- **Vivado IPI Boundary:** [vivado/canary_fir_bd_wrapper.v](vivado/canary_fir_bd_wrapper.v) (pure Verilog-2001 wrapper exposing `s_axil`, `s_axis`, `m_axis`, `clk`, `rst_n`, and `ovf_sticky_o` via `X_INTERFACE_INFO` / `X_INTERFACE_PARAMETER` for `create_bd_cell -type module`).
- **Constraints:** [vivado/constraints.xdc](vivado/constraints.xdc) (`set_false_path -to [get_ports -quiet ovf_sticky_o*]`) and [vivado/impl_cdc.xdc](vivado/impl_cdc.xdc) (must be tagged `USED_IN {implementation}`).

### 3.2 Clock, Reset & CDC Contract
- **Clocking:** Single synchronous clock `clk` targeting `245.761 MHz` (`4.069 ns`).
- **Reset Warning (`rst_n`):** `rst_n` is **synchronous active-low** and resets AXI4-Lite registers, valid/last/overflow pipeline control, and `u_out_skid`. The 14-tap shift line `d[0:13]` and DSP datapath (`p_s1`, `prod_s2`, `sum_s3`, `bypass_s1..s3`, `core_tdata_q`) are intentionally **reset-free** for `SRL16E` and `DSP48E2` packing—asserting `rst_n` clears valid state, **not** sample history in `d[0:13]`.
- **CDC Constraints:** Keep async `set_clock_groups` between `ps8/pl_clk0` and `clk_wiz_core/clk_out1` plus `peripheral_aresetn` `MAX_FANOUT_MODE CLOCK_REGION` / `FORCE_MAX_FANOUT 256` inside a `USED_IN {implementation}` XDC (`vivado/impl_cdc.xdc`).

### 3.3 AXI4-Stream Throughput, Latency & Framing Contract
- **Throughput (`II`):** `II = 1` sample/clock cycle (`245.761 MSPS` peak) when `m_axis_tready = 1`.
- **Latency:** `5` clock cycles (`p_s1` -> `prod_s2` -> `sum_s3` -> `core_tdata_q` -> `u_out_skid`) under `m_axis_tready = 1`.
- **Backpressure & `TLAST`:** `u_out_skid` (`axis_skid`) registers forward and `tready` paths across subsystem boundaries; tail samples drain automatically during `s_axis_tvalid` bubbles (`pipe_en = !core_tvalid_q || core_tready`). `s_axis_tlast` propagates 1:1 with each sample.

## 4. Common Integration Pitfalls & Troubleshooting

| Symptom | Root Cause | Resolution |
| :--- | :--- | :--- |
| `mrd 0xA0000000` hangs (`DAP ACK` timeout) or reads `0x00000000` | Zynq PS-PL isolation locked (ran `fpga -f` without `psu_init` + isolation removal) or `clk_wiz` unlocked | Run [`bringup/jtag_bringup.tcl`](bringup/jtag_bringup.tcl) (`psu_init` -> `fpga` -> `psu_post_config` -> `psu_ps_pl_isolation_removal` -> `psu_ps_pl_reset_config`) |
| Writing `COEFF[0..7]` does not update filter response | Partial `wstrb` (`wstrb[1:0] != 2'b11`) ignored by `canary_fir_regs.sv` | Perform full 32-bit aligned writes (`wstrb = 4'hF`) using `canary_fir_pack_coeff()` / `pack_coeff()` |
| First `14` samples after changing `COEFF` or `CTRL[0]` mismatch golden | Reset-free SRL shift chain `d[0:13]` holds tail samples from prior burst | Push `14` zero samples (`FLUSH_ZEROS = 14`) after switching filter profiles or modes |
| `create_bd_cell -type module` fails on `canary_fir_top` | Vivado IPI rejects unpacked SV array ports (`coeff_o [0:7]`) or SV interfaces | Reference [`vivado/canary_fir_bd_wrapper.v`](vivado/canary_fir_bd_wrapper.v) instead of `canary_fir_top.sv` directly |
| Synthesis reports missing clock pins on `set_clock_groups` | Async CDC XDC evaluated during OOC synthesis | Keep [`vivado/impl_cdc.xdc`](vivado/impl_cdc.xdc) tagged `USED_IN {implementation}` |
