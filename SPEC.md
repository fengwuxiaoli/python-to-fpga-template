## 1. Scope, Goals & Non-Goals

### 1.1 Problem Statement & Functional Goal
- Provide a clean, self-contained, end-to-end **canary DSP block** (`canary_fir`) that exercises the entire **Stage 0 -> Stage 2F** Python-to-FPGA workflow on AMD Zynq UltraScale+ (`ZCU102` @ `245.761 MHz`).
- Filter a signed 16-bit Q1.15 AXI4-Stream input stream through a 15-tap linear-phase symmetric FIR with runtime AXI4-Lite coefficient reprogramming, soft bypass, sticky overflow telemetry, and full AXI4-Stream backpressure/bubble tolerance.

### 1.2 In-Scope Deliverables
- **Stage 1:** Floating-point + bit-exact fixed-point Python golden model ([`python/canary_fir_golden.py`](python/canary_fir_golden.py)) and `$readmemh` vector generator ([`python/generate_canary_vectors.py`](python/generate_canary_vectors.py)) producing 5 committed `.mem` files in [`test_vectors/`](test_vectors/).
- **Stage 2A–2C:** Synthesizable SystemVerilog RTL ([`rtl/axis_skid.sv`](rtl/axis_skid.sv), [`rtl/canary_fir_regs.sv`](rtl/canary_fir_regs.sv), [`rtl/canary_fir_core.sv`](rtl/canary_fir_core.sv), [`rtl/canary_fir_top.sv`](rtl/canary_fir_top.sv)), lint scripts ([`sim/run_lint.bat`](sim/run_lint.bat), [`sim/run_lint.sh`](sim/run_lint.sh), [`vivado/run_lint.tcl`](vivado/run_lint.tcl)), and self-checking XSim testbench ([`tb/tb_canary_fir.sv`](tb/tb_canary_fir.sv)).
- **Stage 2E–2F:** Verilog-2001 IPI wrapper ([`vivado/canary_fir_bd_wrapper.v`](vivado/canary_fir_bd_wrapper.v)), OOC budget script ([`vivado/run_ooc_synth.tcl`](vivado/run_ooc_synth.tcl)), Zynq MPSoC + AXI DMA Block Design ([`vivado/create_bd.tcl`](vivado/create_bd.tcl)), timing/CDC XDCs ([`vivado/constraints.xdc`](vivado/constraints.xdc), [`vivado/impl_cdc.xdc`](vivado/impl_cdc.xdc)), checkpointed bitstream builder ([`vivado/build_bitstream.tcl`](vivado/build_bitstream.tcl)), and Phase 1 XSDB JTAG bring-up ([`bringup/jtag_bringup.tcl`](bringup/jtag_bringup.tcl)).

### 1.3 Explicit Non-Goals (Out of Scope)
- Multi-channel time-division multiplexing (TDM) or polyphase interpolation/decimation.
- External transceiver/RF front-end bring-up (JESD204C, 10GBASE-R, FMC) in the template canary (reserved for user-specific Phase 2 bench designs).
- AXI4-Stream `TKEEP`/`TUSER`/multi-beat burst DMA scatter-gather (simple AXI DMA single-channel 16-bit loopback is used in `create_bd.tcl`).

## 3. Algorithm & Mathematical Specification

### 3.1 Mathematical Definition / Transfer Function
- Causal 15-tap linear-phase symmetric FIR (`NUM_TAPS = 15`, `NUM_SYM_TAPS = 8` unique taps `[h0..h7]`):
  $$y[n] = \sum_{k=0}^{6} h_k \cdot (x[n-k] + x[n-(14-k)]) + h_7 \cdot x[n-7]$$
- Symmetric kernel expansion: `[h0, h1, h2, h3, h4, h5, h6, h7, h6, h5, h4, h3, h2, h1, h0]`.
- **Default Q1.15 Taps (`DEFAULT_TAPS`):** `[-214, -327, 0, 992, 2525, 4351, 5839, 6435]` (`2 * sum(h0..h6) + h7 = 32767`, unity DC gain).
- **Alternate Test Taps (`CUSTOM_TAPS`):** `[0, 0, -512, 0, 2048, 4096, 6144, 9215]` (`2 * sum(h0..h6) + h7 = 32767`).

### 3.2 Operating Modes
- **Normal Filtering (`CTRL[0] = 0`):** Output equals rounded/saturated symmetric FIR convolution of incoming stream against `COEFF[0..7]`.
- **Soft Bypass (`CTRL[0] = 1`):** Output passes the delay-aligned input sample (`bypass_s3`) unchanged (`m_axis_tdata = s_axis_tdata` aligned through the 4-stage core + output skid) and suppresses `ovf_pulse_o`.
- **Runtime Coefficient Reprogramming:** Software writes `COEFF[0..7]` via AXI4-Lite (`0x10..0x2C`). Because the delay line `d[0:13]` is reset-free, callers switching filter profiles cleanly flush `14` zero samples (`NUM_TAPS - 1`) before the next burst.

### 3.3 Framing, Startup & Edge-Case Behavior
- **Power-On / Initial State:** `d[0:13]` and datapath pipeline registers initialize to `0`; `v_s1_q..core_tvalid_q` initialize to `0`.
- **`TLAST` Propagation:** `s_axis_tlast` travels alongside the sample through `last_s1_q -> last_s2_q -> last_s3_q -> core_tlast_q -> u_out_skid` so output packet framing matches input sample framing 1:1.
- **Bubble & Backpressure Drain:** Pipeline shifts on `pipe_en = !core_tvalid_q || core_tready` (independent of `s_axis_tvalid`) while `d[0:13]` only shifts on `s_axis_tvalid && pipe_en`, ensuring tail samples drain cleanly during `s_axis_tvalid` gaps and `m_axis_tready` stalls.

## 4. Fixed-Point Architecture & Numerical Requirements

### 4.1 Bit-Width & Q-Format Table

| Signal / Stage | Signedness | Width & Q-Format | Range / Guard Bits | Notes |
| :--- | :---: | :---: | :---: | :--- |
| **Input (`s_axis_tdata`)** | `Signed` | `16-bit Q1.15` | `[-32768, 32767]` | 2's complement (`1.0 == 32768`) |
| **Coefficients (`COEFF[0..7]`)** | `Signed` | `16-bit Q1.15` | `[-32768, 32767]` | Symmetric taps `h0..h7` |
| **Symmetric Pre-Adder (`p_s1[0:7]`)** | `Signed` | `17-bit Q2.15` | `+1` guard bit | Prevents symmetric sum wrap on `-32768 + -32768` |
| **Multiplier Product (`prod_s2[0:7]`)** | `Signed` | `33-bit Q3.30` | Full `17b x 16b` product | Maps to `DSP48E2 MREG` |
| **Pairwise Adder Tree (`sum_s3[0:3]`)** | `Signed` | `35-bit Q5.30` | `+2` sign-extended guard bits | Registered stage 3 |
| **Final Accumulator (`acc_comb`)** | `Signed` | `38-bit Q8.30` | Sign-extended from 35-bit | No overflow across all 8 products |
| **Output (`m_axis_tdata`)** | `Signed` | `16-bit Q1.15` | `[-32768, 32767]` | Post-round & clamp |

### 4.2 Rounding, Saturation & Python-to-SV Bit-Exact Parity
- **Rounding Mode:** Half-up via arithmetic right shift:
  - Python: `scaled = (acc + 16384) >> 15`
  - SystemVerilog: `scaled_comb = (acc_comb + 38'sd16384) >>> 15`
- **Saturation & Overflow Reporting:** Clamp `scaled` to `[-32768, 32767]`. When clamping occurs on a valid non-bypassed sample (`v_s3_q && !bypass_en_i && ovf_comb`), pulse `ovf_pulse_o` for 1 cycle to latch sticky `STATUS[0]`.
- **`.mem` Export Format:** 4-digit uppercase 2's-complement hex (`val & 0xFFFF:04X`) for `$readmemh`.

### 4.3 Quantitative Acceptance Targets

| Metric | Pass Threshold | Test Stimulus / Condition |
| :--- | :--- | :--- |
| **DC Sum Parity** | `2 * sum(h0..h6) + h7 == 32767` | Verified for both `DEFAULT_TAPS` and `CUSTOM_TAPS` |
| **DC Magnitude Gain** | `|Gain(0)| < 0.01 dB` | Frequency response check (`-0.0003 dB` baseline) |
| **Stopband Attenuation (`0.42 * fs`)** | `< -35.0 dB` | Frequency response check (`-56.93 dB` baseline) |
| **Nyquist Attenuation (`0.50 * fs`)** | `< -40.0 dB` | Frequency response check (`-45.85 dB` baseline) |
| **Float vs. Fixed Max Error** | `<= 0.51 LSB` | 256-sample impulse + `0.05*fs` / `0.42*fs` two-tone (`0.5000 LSB` baseline, `0` overflows) |
| **Saturation Overdrive Check** | `ovf_count > 0` and clamp to `32767` | 16 samples of `+32767` with `3x` gain taps `[0..0, 32767, 32767]` |

## 5. Hardware Interfaces & Register Map

### 5.1 Port & Streaming Interfaces
- **Clock & Reset:** `clk` (rising edge), `rst_n` (synchronous active-low).
- **AXI4-Stream Slave (`s_axis`):** `s_axis_tdata[15:0]`, `s_axis_tvalid`, `s_axis_tready`, `s_axis_tlast`.
- **AXI4-Stream Master (`m_axis`):** `m_axis_tdata[15:0]`, `m_axis_tvalid`, `m_axis_tready`, `m_axis_tlast` via registered 2-entry `axis_skid`.
- **Sideband Telemetry:** `ovf_sticky_o` (active-high sticky overflow flag exported externally in IPI BD).
- **IPI Wrapper:** Pure Verilog-2001 [`vivado/canary_fir_bd_wrapper.v`](vivado/canary_fir_bd_wrapper.v) exposing `s_axil`, `s_axis`, `m_axis`, `clk`, `rst_n`, and `ovf_sticky_o`.

### 5.2 AXI4-Lite Register Map
- **Bus Geometry:** 32-bit data, 8-bit byte address (`256 B` window), base address `0xA0000000` in Zynq MPSoC Block Design (`vivado/create_bd.tcl`).

| Offset | Name | Access | Reset Value | Bit Fields & Description |
| :---: | :--- | :---: | :---: | :--- |
| `0x00` | `VERSION` | `RO` | `0x46495231` | Constant 4-byte ASCII ID `"FIR1"` for Phase 1 JTAG/PS liveness |
| `0x04` | `CTRL` | `RW` | `0x00000000` | `[0]`: `bypass_en` (`1` = bypass, `0` = normal filter); requires `wstrb[0]` |
| `0x08` | `STATUS` | `R/W1C` | `0x00000000` | `[0]`: `ovf_sticky` (latched by `ovf_pulse_i`; write `1` with `wstrb[0]` clears to `ovf_pulse_i`) |
| `0x10..0x2C` | `COEFF[0..7]` | `RW` | `DEFAULT_COEFFS[0..7]` | Signed 16-bit Q1.15 symmetric taps in `[15:0]` (sign-extended on read; requires `wstrb[1:0] == 2'b11` on write; `COEFF[7]` @ `0x2C` = `6435` = `0x00001923`) |
